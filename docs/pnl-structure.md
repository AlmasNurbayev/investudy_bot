# Структура ОПиУ

Черновик для правки руками. Каждая строка отчёта — либо **раздел** (сумма
проводок по отбору), либо **итог** (сумма предыдущих строк). Порядок строк
в таблице = порядок строк в отчёте сверху вниз.

Отбор раздела — **по статье**. Проверено на данных: у каждой статьи ровно
один вид и ровно один тип, поэтому статья определяет их обоих, а не наоборот.
Тип и вид в отборе не участвуют — см. «Почему по статье» ниже.

Числа — срез №4 (06.09.2026 08:49), период `2026-01-01 … 2026-08-31`.

## Виды ОПиУ

**месячные - квартальные - годовые**
Собираются по закрытым периодам, когда в данных минимальные начисления и берут просто все суммы SUM_dash по отборам

**недельные - оперативные**
Собираются по открытым периодам, когда в данных много начислений (type_oper 2 и 4) и по многим статьям/подстатьям сумму не брать как есть, а необходимо высчитывать пропорционально периодам или использовать коэффициент.

## Разделы

(расходы в `sum_dash` уже отрицательные). Доступ по ролям — до строки
**включительно**, колонка «Видна до».

## Почему отбор по статье, а не по типу и виду

За одно утро 06.09.2026 классификация в источнике менялась дважды, при
неизменных 25 790 строках:

| Статья            | Срез 1 (02.09)        | Срез 2–3 (08:00–08:19)   | Срез 4 (08:49)              |
| ----------------- | --------------------- | ------------------------ | --------------------------- |
| `дивиденды`       | `движение` / без вида | `движение` / `дивиденды` | **`расход`** / `дивиденды`  |
| `займы`           | `доход` / без вида    | `доход` / без вида       | **`движение`** / `движение` |
| `инвест. доходы`  | `расход` / без вида   | `расход` / без вида      | `расход` / **`прочая`**     |
| `инвест. расходы` | `расход` / без вида   | `расход` / без вида      | `расход` / **`прочая`**     |

Отчёт, построенный на типе и виде, изменил бы чистую прибыль за 2026 год
на **159.9 млн** между 08:19 и 08:49 — дивиденды переехали из `движение`
(не считается) в `расход` (считается). Отбор по статье это событие
не заметил: `дивиденды` как были отдельным разделом, так и остались.

Отсюда же следует, что счётчик «статьи вне структуры» обязателен: справочник
статей растёт в Google Sheets сам, а список разделов правится здесь руками.
Новая статья иначе выпадет из отчёта молча, с заполненной суммой.

## Замечания по данным

- **Дивиденды за 8 месяцев (−159.9 млн) вдвое превышают чистую прибыль
  (86.4 млн).** Если структура верна, распределено больше заработанного.
- `инвест. доходы` имеет тип `расход` и сумму со знаком **плюс**;
  `сообщества доходы` — то же самое.
- Появился вид `движение`, совпадающий по названию с типом `движение`.
- `админ. расходы` и `общие налоги` встречаются ровно в одном подразделении —
  раскрывать их по подразделению нечем, остаётся подстатья.
