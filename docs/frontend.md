# Фронтенд

Предполагается сделать веб-страницу SPA на react.

## Авторизация и аутентификация

Через логин-пароль. Нужны длинные сессии, чтобы было удобно руководителям.
Закрытая страница администратора для создания/редактирования новых пользователей - поля для логин, пароль, уровень доступа. Действия с пользователями - создать, заблокировать, изменить логин, изменить пароль (без запроса старого), изменить уровень доступа.

## Разделы сайта

1. Дашборд - набор диаграмм за текущий год

- Выручка за текущий год и выручка за прошлый год (из ОПиУ 1.1 + 1.2) - помесячно 2 ряда данных
- Операционная прибыль, чистая прибыль за текущий год и за прошлый год (из ОПиУ 4 + 6) - помесячно 2 ряда данных

2. ОПиУ недельная
   выбор года (по умолчанию текущий), месяца (по умолчанию текущий)
   Выходная форма - таблица со всеми неделями за текущий месяц

3. ОПиУ месячная
   выбор года (по умолчанию текущий), тип периода - месяц/квартал/год, количество колонок, выбор периода для каждой колонки
   Выходная форма - таблица с несколькими периодами

4. Детальные данные из БД с произвольным отбором
   обязательные отборы - снепшот (по умолчанию последний заполненный), период (по умолчанию текущий месяц),
   необязательные отборы - статья, подстатья, подразделение
   Выходная форма - плоская таблица со всеми доступными полями, нужные поля настраиваются.

5. Займы

6. Внутренные движения
